# Gemini 猫耳娘「真动画」视频生成指南

## 准备工作

1. **上传参考底图**：打开即梦 / 可灵 / 豆包 / Runway / Veo 等图生视频工具，选择 **16:9 横屏**。
   - 常态及各种动作的首帧：**上传本目录的 `base_idle_green_16x9.png`**（如果工具支持「首尾帧参考」，**尾帧也上传同一张 `base_idle_green_16x9.png`**，播放循环时零跳变）。
   - 睡觉无限循环动作的首帧（与尾帧）：**上传 `base_sleep_green_16x9.png`**。
2. **建议时长**：`5s` 或 `10s` 均可。
3. **成品存放位置**：生成的 `.mp4` 直接保存/拷贝到 `neko-studio/videos/` 目录下，文件名按下方对应命名，全部放进去后通知我即可自动抠像并集成！

## 复制即用的分镜提示词

> 下面每一段提示词均已包含「纯绿幕 #00FF00、固定镜头与站位、全画幅防切边、无→有→无道具闭环」等约束，直接整段复制即可。
