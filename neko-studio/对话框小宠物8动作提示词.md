# 对话框上沿小宠物 — 8 个专属「真动画」生成提示词

## 一、生成规范与准备
1. **参考底图（首尾帧）**：
   - 使用图生视频工具（即梦 / 可灵 / Veo / Runway 等），选择 **16:9 横屏**（或 1:1 均可，建议 16:9 留足安全边距）。
   - **首帧与尾帧**（若支持首尾帧锁定）统一上传 `neko-studio/base_idle_green_16x9.png`（趴睡循环那一条使用 `neko-studio/base_sleep_green_16x9.png`）。
2. **核心约束（已内置于每条提示词中）**：
   - **纯绿幕 `#00FF00`**，无地面阴影、无杂物、**严禁出现任何文字、字幕、贴纸或气泡**。
   - **固定机位、底部对齐不位移**，头顶呆毛与两侧发梢全程保留在画面安全区内不裁切。
   - **首尾帧完全一致**（道具遵循「无 → 浮现 → 消散 → 无」闭环），保证循环切换零跳帧。
3. **成品存放目录**：
   - 生成后的 `.mp4` 文件放入 `neko-studio/videos/` 目录，按下方文件名命名即可，随后可使用 `clean_greenscreen_webm.py` 抠除绿幕并压制为透明通道 WebM！
